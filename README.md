# DNN Numerical Range and Precision Analysis

## 1. Objective

This project analyzes the numerical range and precision of data used and generated by deep neural networks during training and inference.

The objective is to determine whether lower-precision numerical representations such as FP16, FP8, INT16, and INT8 may be sufficient in place of FP32 for different types of DNN data.

All neural-network training and inference computations in this project are performed using FP32. Lower-precision formats are evaluated through numerical range and precision analysis only.

## 2. Models and Datasets

### Training Analysis

* Model: ResNet-18
* Dataset: CIFAR-10
* Data representation: FP32
* Training epochs: 30
* Training stages:

  * Beginning: Epoch 1
  * Middle: Epoch 15
  * End: Epoch 30

The following quantities were analyzed separately by layer:

* Inputs
* Weights
* Activations
* Gradients
* Weight updates
* Bias values

### Inference Analysis

The following model-dataset combinations were analyzed:

* ResNet-18 on CIFAR-10
* MobileNetV2 on CIFAR-100
* LeNet-5 on MNIST

The following quantities were collected:

* Inputs
* Weights
* Activations
* Bias values
* Output logits

A complete test-dataset inference pass was performed for each model.

## 3. Numerical Analysis

For each layer and data type, the following quantities were calculated:

* Minimum value
* Maximum value
* Maximum absolute magnitude
* Smallest nonzero magnitude
* Percentage of zero values
* Minimum observed spacing between distinct FP32 values
* Dynamic range

Dynamic range is calculated as:

$$
\text{Dynamic Range}
=
\frac{\max |x|}
{\min_{x\neq0}|x|}
$$

The logarithm of the dynamic range is also reported in orders of magnitude.

## 5. Lower-Precision Analysis

The FP32 observations are used to assess the suitability of:

* FP16
* FP8 E4M3
* FP8 E5M2
* INT16
* INT8

For FP16 and FP8, numerical range and approximate representability are examined.

For INT16 and INT8, symmetric per-tensor scaling is considered using:

$$
S=\frac{\max |x|}{Q_{\max}}
$$

where \(Q_{\max}=32767\) for INT16 and \(Q_{\max}=127\) for INT8.

The resulting quantization step and potential loss of very small values are evaluated.

No lower-precision neural-network implementation is used.

## 6. Key Findings

The largest observed dynamic range occurred in the gradients:

$$
3.36\times10^{11}
$$

followed by weight updates:

$$
3.16\times10^{10}
$$

The worst observed dynamic ranges for the major training quantities were approximately:

| Data Type      | Maximum Observed Dynamic Range |
| -------------- | -----------------------------: |
| Gradients      |          \(3.36\times10^{11}\) |
| Weight updates |          \(3.16\times10^{10}\) |
| Weights        |             \(2.33\times10^9\) |
| Activations    |             \(4.55\times10^7\) |
| Inputs         |             \(3.38\times10^7\) |
| Biases         |             \(4.79\times10^4\) |

The results indicate that weights, activations, biases, and many inference quantities are generally more amenable to reduced precision than gradients and weight updates.

FP16 appears to be a strong candidate for many DNN quantities based on the observed numerical ranges. FP8 has greater precision limitations near zero and is more sensitive to the distribution of individual layers.

INT8 and INT16 can represent data after suitable scaling, but a single per-tensor scale may cause very small values to round to zero when the tensor has a large dynamic range.

## 9. Execution

Create and activate a Python virtual environment, install the required packages, and run:

```bash
python dnn_precision_analysis.py
```

The numerical analysis output is saved under:

```text
results/csv/
```

and the distribution plots are saved under:

```text
results/plots/
```

The post-processing precision analysis can be run with:

```bash
python final_precision_report.py
```

The final training summary can be generated with:

```bash
python final_summary_table.py
```
